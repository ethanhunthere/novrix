# NOVRIX

**Live:** [novrix.io](https://novrix.io)

On-chain intelligence infrastructure. Sentiment analysis, whale tracking, and DeFi macro-economics. Desktop-only terminal UI.

---

## Stack

Next.js 16 · TypeScript · Tailwind CSS v4 · Recharts · Cloudflare Pages · Cloudflare D1 · Cloudflare Workers

---

## Commands

```bash
pnpm install
pnpm run dev
pnpm run build
npm run deploy
```

---

## Data Partners

NOVRIX would not exist without the following data providers and infrastructure:

**[BGeometrics](https://bgeometrics.com)** — Bitcoin on-chain analytics. We access data through **5 separate API keys** (`BGEOMETRICS_API_KEY` through `BGEOMETRICS_API_KEY_5`) to cover the full breadth of on-chain metrics.

**[FRED](https://fred.stlouisfed.org)** (Federal Reserve Economic Data) — Macroeconomic indicators including interest rates, inflation, employment, GDP, money supply, and treasury yields.

**[DeFi Llama](https://defillama.com)** — DeFi TVL, protocol fees, revenue, DEX volumes, stablecoins, and yield pools.

**[CoinGecko](https://coingecko.com)** — Cryptocurrency prices, market data, and global metrics.

**[CoinMarketCap](https://coinmarketcap.com)** — Market dominance and global cryptocurrency metrics.

**[Alternative.me](https://alternative.me/crypto/fear-and-greed-index)** — Crypto Fear & Greed Index.

**[Binance](https://binance.com)** — Derivatives data including funding rates, open interest, and long/short ratios.

**[Helius](https://helius.xyz)** — Solana SPL token transactions and data.

**Blockchain Data:** Blockchair · Blockstream · Mempool.space · Etherscan · Ethplorer · Solscan · TronScan · Whale Alert

**News:** CoinTelegraph · Investing.com RSS

All trademarks and data belong to their respective owners. NOVRIX aggregates and presents this data for analytical purposes only.
